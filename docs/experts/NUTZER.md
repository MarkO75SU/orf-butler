# Rolle: Nutzer (Der Auftraggeber)

## Mandat
- Hat das letzte Wort bei allen Code-Änderungen an der App.
- Definiert die Business-Requirements (Bilinguale PWA, RSS, etc.).
- Freigabe-Instanz für Deployments.

## Aktuelle Vorgaben
1. Keine Google-Fonts.
2. Eigene Icons/Emojis (SVG).
3. Lizenzfreie Bilder.
4. GitHub-Push Regelung:
   - Mit Vercel: Nur mit Zustimmung.
   - Ohne Vercel: Automatisch nach Änderung.
