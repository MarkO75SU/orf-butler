# ORF-Butler (OpenRouter Free Butler)

**Konfiguriere kostenlose OpenRouter-KI-Modelle für deine Entwicklungsumgebung – mit einem Klick.**

![Tests](https://github.com/MarkO75SU/orfb/actions/workflows/daily-update.yml/badge.svg)

---

## Features

- **22+ Free-Modelle** – automatisch täglich aktualisiert via OpenRouter-API
- **NEU-Markierung** – neue Modelle erscheinen mit Badge ganz oben
- **12 Tools** – Continue, Cursor, Windsurf, Claude Code, Aider, GitHub Copilot, Cline, Codeium, OpenCode, Zed, Amazon Q, Antigravity
- **Config-Export** – JSON/YAML/Instruction pro Tool, gebündelt als ZIP
- **Auto-Installer** (Premium) – native Launcher für Win/Mac/Linux, kopiert Configs an die richtigen Pfade
- **Tool-spezifische INSTALL.md** – exakte Installations- und Konfigurationsanleitung
- **Anonymer Code-Login** – kein Account nötig, einfach Code eingeben
- **Bilingual** – Deutsch / Englisch

## Quick Start

```bash
npm install
npm start        # http://localhost:3000
npm test         # 448 Tests
```

## Deployment

Automatisch via GitHub → Vercel. Jeder Push auf `main` deployed live.
